# vscode_esa_explorer
esa.ioの記事をVisual Studio Code上で一覧・検索・閲覧・編集できる拡張機能です。専用ビューにカテゴリ階層と記事一覧を表示し、選択した記事をMarkdownエディタで開いて編集・保存できます。esa Public API v1とPersonal Access Token v2を利用し、認証情報はVS CodeのSecretStorageで管理します。将来的には記事作成、タグ・WIP管理、全文検索、更新競合の検知、履歴確認、AIチャットによる要約・校正・記事作成支援にも対応し、esaを中心としたドキュメント管理とIssue駆動開発をVS Code内で完結させることを目指します
